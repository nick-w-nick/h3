# Getting Started

> Getting started with h3

## Overview

h3 (short for HTTP, pronounced as /eɪtʃθriː/, like h-3) is a lightweight and [composable](/utils) server framework for JavaScript that is designed to
work with various JavaScript runtimes through [adapters](/adapters).

::read-more{to="https://nitro.unjs.io"}
Check out [Nitro](https://nitro.unjs.io) for a full featured server toolkit.
::

## Quick Start

Create a new file `app.ts` (or `app.js`):

```ts [app.ts]
// Import h3 as an npm dependency
import { createH3 } from "h3";

// Create an app instance
export const app = createApp();

// Add a new route that matches GET requests to the / path
app.get("/", defineEventHandler((_event) => {
  return {
    message: "⚡️ Tadaa!",
  };
}));
```

Now run the development server using **[unjs/listhen](https://listhen.unjs.io)**:

```sh
npx --yes listhen -w --open ./app.ts
```

> [!TIP]
> You don't need to install any additional dependencies using this method. **[unjs/listhen](https://listhen.unjs.io)** has a preinstalled version of h3!

Tadaa 🎉! We have a web server running locally!

### What happened?

Okay, let's now break down our hello world example:

We first created an [app instance](/guide/app) using the `createH3()` method. The h3 `app` instance is a tiny server capable of handling routing, request and response parsing, as well as processing lifecycle hooks (see [Lifecycle Hooks](/guide/app#lifecycle-hooks) for more information):

```ts
export const app = createH3();
```

Then we registered a new route that can match `GET` requests to the `/` path. We used the `app.get()` method to register a new event handler that returns a simple JSON object with a default status code of `200` provided by h3:

```ts
app.get("/", defineEventHandler((_event) => {
  return {
    message: "⚡️ Tadaa!",
  };
}));
```

What is beautiful in h3 is that all you have to do to make a response, is to simply return it! Responses can be simple string, JSON objects, data buffers, streams or a standard [Web Response](https://developer.mozilla.org/en-US/docs/Web/API/Response/Response).

> [!TIP]
> See [Response Types](/guide/event-handler#response-types) for a list of supported response types.

In this example, we returned a simple JSON object with a message property containing the string `"⚡️ Tadaa!"`:

```ts
return { message: "⚡️ Tadaa!" };
```

Finally, we use [unjs/listhen](https://listhen.unjs.io) CLI using npx to auto install it. Listhen will automatically setup and start our webserver with zero configuration and adds on-the-fly TypeScript support to your experience!

```sh
npx --yes listhen -w --open ./app.ts
```

### Running without `listhen`
h3 was built to be a portable request handler that is compatible with a majority of HTTP frameworks. You can use the `toNodeHandler` utility to convert an h3 app to a request handler that can be passed to your framework of choice.

Here's an example using a simple Node.js HTTP server with h3 as the request handler:
```ts
import { createH3, toNodeHandler, defineEventHandler } from "h3";
import { createServer } from "node:http";

const app = createH3();

app.get("/", defineEventHandler((_event) => {
  return {
    message: "Tadaa! 🎉",
  };
}));

const handler = toNodeHandler(app);
const server = createServer(handler);

const PORT = process.env.PORT || 3000;

server.listen(PORT, () => {
  console.log(`Server listening on port ${PORT}`);
});
```

## Installing h3

h3 can be installed as an `npm` package or imported directly from a CDN.

### Installing from `npm`

> [!TIP]
> This is the recommended way to install h3 when using Node.js.

::pm-install{name="h3"}

::

### Importing from a CDN

You can import h3 directly from a CDN if desired. This method can be used for Bun, Deno, as well as edge runtimes such as Cloudflare Workers (see [adapters](/adapters) for more information).

```ts
import { createH3, toWebHandler } from "https://esm.sh/h3";

export const app = createH3();

export const handler = toWebHandler(app);
```
