# Event Object

> The `Event` object carries all of the information about the current HTTP request and response being handled by your event handler.

Every time a new HTTP request is recieved, h3 internally creates an `Event` object and passes it through the registered event handlers until a response is returned.

> [!TIP]
> An event is passed through all of the available [lifecycle hooks](/guide/app#lifecycle-hooks) and composable utilities to use it as context throughout the request lifecycle.

**Example:**

```ts
import { getQuery, readJSONBody } from "h3";

app.use(async (event) => {
  // Log the request event
  console.log(`Request: ${event.toString()}`); // `Request: [GET] /<path>`
  
  // return the parsed event as the response
  return {
    path: event.path,
    method: event.method,
    query: event.query,
    body: event.request.json(),
  };
});
```

## Properties

The main properties of an event are:

### `event.request`

Contains the [Request](https://developer.mozilla.org/en-US/docs/Web/API/Request) object of the incoming request.

### `event.response`

Contains the [Response](https://developer.mozilla.org/en-US/docs/Web/API/Response) object of the outgoing response.

### `event.method`

Contains the normalized (uppercase) request [method](https://developer.mozilla.org/en-US/docs/Web/HTTP/Methods).

### `event.path`

Contains the request path. (**Example:** `/test?test=123`)

### `event.context`

The context is an object that contains arbitrary information about the request.
You can store custom properties inside `event.context` to share across composable utilities.
